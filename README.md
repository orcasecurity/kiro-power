# Orca Security Power for Kiro

Connects [Kiro](https://kiro.dev) to the [Orca Security MCP server](https://orca.security/mcp-server/), so the agent can triage alerts, explore assets and attack paths, query your cloud inventory, and track compliance using live data from your Orca account.

## Install

In Kiro, open **Powers** → **Add Custom Power** → **Import power from GitHub** and paste:

```
https://github.com/orcasecurity/kiro-power
```

## Authentication

The power uses OAuth.
On first use, Kiro opens a browser window to sign in with your Orca account.
